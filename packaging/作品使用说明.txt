A3 学习 AI - 比赛作品使用说明
================================

系统要求
--------
- Windows 10/11 64 位
- MySQL 8.x 已安装并启动
- 首次使用资料向量功能需要联网下载 Embedding 模型
- AI 对话需要用户在设置页填写自己的 OpenAI 兼容 API

启动方法
--------
1. 双击“A3学习AI.exe”。
2. 首次启动填写 MySQL 地址、端口、用户名、密码和数据库名。
3. 程序会自动创建数据库、执行迁移并打开浏览器。
4. 注册/登录后，进入“设置 -> 模型服务”填写：
   - Base URL（例如 https://api.openai.com/v1）
   - 模型名称
   - API Key
5. 测试连接成功后即可使用。

说明
----
- API Key 加密保存，不会写入本作品压缩包。
- 运行时请保留程序控制台窗口；关闭窗口即停止服务。
- 默认访问地址：http://127.0.0.1:8010/
- 配置和本地运行数据仅保存在解压后的作品目录及 MySQL 数据库中。
- 若端口 8010 被占用，可在命令行运行：A3学习AI.exe --port 8011

常见问题
--------
- 提示数据库连接失败：确认 MySQL 服务已启动，用户名/密码正确，并具有建库权限。
- 页面没有 AI 回复：在设置页配置 OpenAI Chat Completions 兼容服务。
- 首次处理资料较慢：程序可能正在联网下载本地 Embedding 模型。
